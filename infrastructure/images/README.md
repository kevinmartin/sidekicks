# Compute images

The clean multi-stage recipe in `clean/` defines all four workload targets. Runtime desktop assets are in `assets/desktop/`; Neko's pinned upstream module overlay is in `desktop-neko/upstream-modules/`. Build, source provenance, dependencies and verification limits are documented in [clean/README.md](clean/README.md).

Historical POC recipes are preserved on the local `reference/poc` branch; their ignored disk images and evidence are not part of that branch.
