# Desktop input boundary

Both current viewers send input through the same Sidekicks-owned `DesktopInput` layer to the authenticated epoch-gated Go `/input` endpoint. The Go driver injects and checks X11 operations under the ownership manager. noVNC RFB is permanently receive-only; Neko's SDK is used for WebRTC media/cursor reception, without its Overlay, native input methods or native ownership grant. Pinned Neko 3.2.0 native input remains unsupported pending an atomic upstream ownership/injection boundary. This is an intentional capability limitation, not native parity.

The frontend supports a US keyboard mapping for letters/digits, base punctuation, real Shift/Control/Alt/Meta, F1–F12, arrows, Enter, Tab, Backspace/Delete, Home/End/PageUp/PageDown, and primary/middle/right pointer actions, drag and two-axis wheel. Shift is transmitted as a held modifier; shifted symbols use the physical unshifted base key. Numpad Multiply, Caps Lock, IME/dead keys/AltGraph, arbitrary international layouts, touch and host clipboard transfer are unsupported. Unsupported input visibly revokes the current frontend epoch and requests server release rather than silently changing characters. Guest-local Ctrl+C/Ctrl+V remain ordinary guest shortcuts.

Coordinates derive from the actual visible bitmap rectangle and clamp at desktop boundaries. Pointer capture preserves button-up delivery outside the bitmap. A human sees one local server-cursor image/hotspot when available; Neko observers see the received remote cursor. No upstream native control transfer is used to display it.

The queue is limited to 256 events, sends at most 32 per checked request, and coalesces only adjacent pointer moves. Every request carries its captured `X-Sidekicks-Epoch`. Releasing/suspending discards queued stale events and held bookkeeping without aborting an in-flight checked X11 request. The server gate serializes/revokes/reset-checks that request; a delayed old response cannot clear a newer frontend epoch. Blur/pagehide/disconnect use a captured-epoch `fetch(..., keepalive:true)` release, never an unversioned beacon. A current media disconnect suspends input; late events from retired streams do not revoke replacement epochs.

The Neko viewer cancels pending Take requests when the user releases input, changes viewer fullscreen, blurs or leaves the page. A release that remains unconfirmed after five seconds, or an unconfirmed acquisition, closes that viewer's signaling connection and requires a page reload before another Take. The backend associates disconnect cleanup with the matching lease; a closed signaling connection alone does not prove that backend reset completed.

`node --test web/desktop/input.test.mjs` exercises mapping, fractional/letterboxed coordinates, bounded queues, suspend/takeover during an in-flight mocked write, old-response fencing, ordered releaseAll, repeated Take retaining receive-only RFB, disconnect generation fencing and captured-epoch blur. These are offline DOM/protocol simulations, not actual browser/desktop evidence. The separately coordinated `test/e2e/desktop.mjs` exercises fresh real streams, normalized delivery, actual held-state release, media-only transports and restart. Physical reserved shortcuts, phones, latency parity and application-event queue flushing are not established by these tests.
