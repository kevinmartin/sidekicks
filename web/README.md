# Browser-side source

Compute viewers and browser-side code belong here. The earlier POC viewer source is preserved on the local `reference/poc` branch; its ignored runtime state and evidence remain separate on disk and are not backed up by that branch. Third-party protocol clients (noVNC and Neko SDK) remain in their native languages alongside Sidekicks UI glue. No new harness or profile UI is scaffolded in this compute increment.
