# Neko media and control boundary

This package connects the Go compute layer to pinned Neko v3.2.0 for signaling, WebRTC video and capture. Neko, Pion, GStreamer and the browser SDK remain third-party components. Human and agent input use the shared, lease-gated Go X11 driver; native SDK input and the upstream controller's asynchronous input WebSocket are disabled. The source-backed reason and limits are in [UPSTREAM-SAFETY.md](UPSTREAM-SAFETY.md).

`New(Config)` requires a literal guest-loopback endpoint and per-instance controller and viewer credentials. `Connect` verifies the administrator role, locked controls and disabled implicit hosting, resets upstream state and establishes the controller. Viewer accounts must have login/connect/watch permission without host, clipboard or media-sharing permission. A disconnected controller invalidates viewer tickets and fences the shared control manager; failed reset leaves control unready. Reconnection does not revive an old lease.

`NewHandler` requires the instance bearer token and rejects `EnableNative: true`. Its private compatibility input route returns an unsupported response; the actual compute input routes use the X11 driver. Private routes reject browser Origins and must not be published. A public wrapper validates Host, Origin and its viewer cookie before forwarding only fixed SDK metadata and signaling paths. Viewer tickets are opaque, short-lived, bound to the cookie session and invalidated when the controller disconnects. Lease cleanup uses exact credentials so an old viewer cannot revoke a replacement owner.

The trusted launcher supplies all twenty inspected Docker UDP mappings for guest ports 60020–60039 before a viewer is created. The handler copies and validates the mapping, and does not change it while viewers exist. It rewrites only the relevant loopback ICE candidate ports in recognized signaling messages; invalid or unexpected UDP candidates fail closed. This supports loopback Docker media allocation, not arbitrary host destinations or a claimed TCP fallback.

`Capture` obtains a bounded upstream JPEG and is separate from observing a decoded WebRTC frame. Reset and checked input do not retract events already delivered to an application. Unit tests use owned fake HTTP/WebSocket servers; real media, X11 behavior and lifecycle require the separate integration and E2E evidence described in the compute status report.
